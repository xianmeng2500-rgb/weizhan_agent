01演示准备

演示前 5 分钟检查，避免现场翻车。

环境检查清单

  • 后台地址可访问：https://您的域名/admin/，能正常登录 demo_admin；
  • H5 地址可访问：/s/demo-launch 与 /s/demo-festival 均能打开；
  • 两个演示账号、H5 登录账号（zhangsan / lisi）密码均为 Demo@123456；
  • 建议用无痕窗口 + 双屏（或浏览器分屏）演示：左屏后台、右屏 H5，同步展示操作与效果；
  • 演示前把「工作台」和「微站列表」刷新到最新状态，避免页面残留。
精简版（8 分钟）

登录后台 → 工作台 → 创建微站（选模板 + AI 生图）→ 报名/签到模块 → 上线 → H5 体验。适合初次接触、时间紧的客户。

完整版（15 分钟）

精简版 + 模板管理 + 账号权限 + 签到核销 + 报名数据 + 分销返佣 + 工作台数据。适合决策型 / 对比选型客户。

按需补讲

客户对哪个卖点追问，直接跳「路线C 进阶卖点」对应小节单独演示。

演示顺序铁律：先演示「快速见效」的（建站、AI 生图），再讲「运营深度」的（签到、数据、分销）。客户的耐心是递减的，开场 3 分钟就要让他看到「3 分钟搭一个微站」。

03路线A：后台功能演示

用 demo_admin 登录后台，按顺序走完 8 步，覆盖从登录到上线全流程。

登录与工作台

打开 /admin/，用 demo_admin / Demo@123456 登录，展示首页。

话术：「登录后所有经营数据一目了然——微站数量、今日访问、访问趋势，还有我的账户和推广信息，不用翻报表。」
模板管理

左侧「模板管理」，展示模板卡片列表；点进一个模板的编辑，展示可视化配置（KV 图 / 背景 / 预置按钮）。

话术：「我们内置多套风格模板，管理员还能自建模板预设外观和按钮，客户建站一键套用、秒级起步。」
创建微站（重点演示）

「微站列表 → 创建微站」→ 选择模板（或空白创建）→ 进入编辑器：

  • 填名称 / 编码；
  • 在 KV 图区域点「AI 生图」，输入「蓝色渐变科技风活动横幅」→ 生成 → 选一张「使用此图」；
  • 背景图同样用 AI 生成一张；
  • 点保存。
话术：「客户不需要会设计，描述一句话，AI 帮你出 KV 图、背景图、图标——这是全流程最打动人的环节，放慢节奏操作。」
配置模块

进入「模块」标签，逐个介绍 5 种模块类型，打开 demo-launch 查看实例：

  • 富文本：活动介绍（图文混排）；
  • 报名表单：表单设计器，字段拖拽配置，可开「提交后允许修改」；
  • 日程安排：时间线展示，支持 CSV 导入；
  • 我的二维码：为登录用户生成专属签到二维码；
  • 外部链接：跳转官网等。
话术：「活动要用的：报名收集、日程公示、现场签到二维码，全都能配，不需要开发。」
账号与权限

打开 demo-launch 的「账号」标签，展示已导入的 zhangsan / lisi 及模块勾选。

话术：「每个账号能看哪些模块可以单独勾选——比如只有报名学员能看培训资料，做定向内容很灵活。」
签到管理

「签到管理 → demo-launch」查看已配置的「上午场 / 下午场」两个场次；说明 PC 摄像头核销与手机 /m/ 扫码核销两种方式。

话术：「现场一个手机就能核销签到，还能人工补签、导出名单，活动主办方最刚需的功能。」
报名数据

「报名数据」查看该微站报名记录，展示备注、单条「可修改 / 禁修改」开关。

话术：「报名数据后台沉淀，可备注跟进；还能控制报名者提交后能否自助修改，灵活又安全。」
上线

回到微站列表，展示「上线」操作消耗 1 个上线额度；打开 H5 地址收尾。

话术：「配置完一键上线，额度用完在会员中心自助购买，商业化闭环完整。」
演示建议：第 3 步「创建微站 + AI 生图」是全流程高潮，建议现场真实操作一次生成，不要只放录屏。

04路线B：H5 端体验

用手机或浏览器移动模拟打开 H5，让客户以「访客」身份体验。建议与路线A同屏对照。

登录体验

打开 /s/demo-launch，展示需登录页（与微站主页同视觉风格）；用 zhangsan / Demo@123456 登录。

话术：「支持密码登录、自定义登录字段，适合定向邀请类活动，访客登录后看到的内容还可以按人区分。」
内容浏览与日程

点「活动介绍」看富文本详情；点「大会议程」按时间线查看日程。

话术：「报名填错了不用找主办方，自己就能改——但要不要开放修改、哪条数据能改，主办方后台完全可控。」
签到二维码

点「签到二维码」模块，展示专属二维码；说明现场核销员扫码即完成签到。

公开微站体验

注意：H5 摄像头扫码功能依赖 HTTPS 环境，演示前确认域名是 HTTPS，否则现场扫码环节会报错。

07常见问题与兜底

演示中可能遇到的问题与客户高频追问。

登录报错 / 演示账号登不上去？
先确认数据库与后端服务已启动；再确认账号未被禁用。若数据异常，可在后端目录执行 python seed_demo.py 幂等重建（不会重复插入），极端情况用 --reset 清空重建。
AI 生图生成很慢或失败？
生成通常需 10-60 秒，属正常。若失败，检查「管理员配置 → AI 服务」的 API Key 是否有效、账户余额是否充足。演示时建议提前生成几张素材备用。
客户问「价格怎么算」？
预充值钱包模式：超管为账号充值余额，客户用余额自助购买。年费会员 499 元 / 年（可创建任意数量微站），微站每上线一次消耗 1 个上线额度（299 元 / 次），下线不退。价格超管可配置调价。
客户问「有没有分销 / 代理政策」？
支持一级分销：推广客户首次购买会员或额度后，按 10% 返佣到钱包余额（比例可配）。合规设计：仅按真实消费计酬、不设团队计酬，规避多级分销风险。具体结算与提现规则可进一步洽谈。
客户问「能接入微信、能统计吗」？
支持微信分享卡片（需配置公众号 AppID/AppSecret）；内置 PV/UV、模块点击、访问趋势统计，后台工作台与微站详情页均可查看。
演示中途被提问打断怎么办？
先回答客户问题再回到主线；若问题超出当前步骤，快速答完并说「这个功能稍后专门演示给您看」，跳转对应小节后记得回到原位置。任何一步卡住，优先跳过，不要在现场排查，事后补演示。
