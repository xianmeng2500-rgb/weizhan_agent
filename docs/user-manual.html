01产品简介

先花 1 分钟了解系统全貌，再进入操作。

1.1 这是什么

微站系统是一套 无需编程的移动端内容展示平台。运营者登录后台，像搭积木一样创建微站：选模板、配模块、导入账号、设置签到，一键上线后用户通过 手机扫码 / 链接 即可访问。常用于企业活动、产品发布、展会签到、会议报名等场景。

1.2 三个入口

后台管理端

PC 浏览器访问 /admin/，运营者在此创建微站、配置内容、管理账号、查看数据。

H5 微站端

手机访问 /s/{微站code}，终端用户在此浏览内容、登录、报名、签到。

移动核销端

手机访问 /m/，现场工作人员用后台账号登录，扫码核销签到、人工补签。

1.3 核心能力一览

多微站并行

一个账号可创建多个微站，每个独立链接、独立管理。

模板体系

内置多套风格模板，管理员可自建模板预设外观与按钮，建站一键套用。

富文本 & 外链

图文混排编辑器，图片上传云端；模块也可直接跳转外部链接。

报名表单

可视化配置报名表单，数据后台沉淀；支持提交后修改、去重与备注。

签到核销

多场次签到，PC 摄像头 / 手机扫码核销，支持补签与撤销。

账号与权限

微站登录账号批量导入，模块级权限按账号分配。

数据统计

PV / UV、模块点击量、访问趋势，实时掌握运营效果。

AI 生图

编辑微站时内置 AI 生图，KV 图、背景、分享图、模块图标一键生成。

时间控制

微站整体与每个模块都可设置开启 / 关闭时间，自动生效。

1.4 角色与权限

角色可见范围账号管理典型使用
super_admin 超级管理员所有微站管理全部后台账号、会员充值 / 退款、套餐配置平台方 / 总负责人
admin 管理员自己创建的微站创建 / 管理自己的子账号；管理模板商家运营者
sub_admin 子账号自己创建的微站无账号管理权限运营团队协作者
提示：后台管理员账号（users）与微站登录账号（site_accounts）是两套独立体系。后台账号用于登录管理后台；微站登录账号用于 H5 端访客登录（如「需要登录」的微站）。

1.5 商业化规则

预充值钱包

由超管为用户账户充值余额，用户用余额自助购买会员与上线额度。

会员 499 元 / 年

开通后可创建 / 管理任意数量微站；到期后微站转为只读，续费恢复。

上线额度 299 元 / 次

微站每上线一次消耗 1 个额度；下线不退，再次上线重新扣减。

注意：没有可用额度时微站无法上线；额度购买后 1 年内有效，过期作废。子账号继承父账号的会员状态与额度。

02快速上手：3 分钟上线一个微站

以下为商家运营者的标准操作路径，共 5 步。

登录后台

打开浏览器访问后台地址（如 https://您的域名/admin/），使用后台管理员账号登录。首次使用请向平台方索取账号，或使用超管分配的管理员账号。

选择模板并创建

左侧菜单「微站管理 → 微站列表」→ 点击「创建微站」，进入模板选择页：

  • 套用模板：从启用模板中选一张卡片，一键带入模板的外观与预置按钮模块，稍作修改即可；
  • 空白创建：不需要模板时，直接进入编辑器从零搭建。

进入创建页后填写：

  • 微站名称：对外展示的站点名称，如「2026 产品发布会」；
  • 微站编码：唯一访问标识，将出现在访问链接中，建议用英文 / 数字；
  • KV 图与背景：套用模板时自动带入；也可上传或点「AI 生图」描述一句自动生成。
配置模块

在微站编辑页进入「模块」标签，点击「添加模块」逐个配置。每个模块可选择类型：

  • 富文本：图文混排内容页，适合公告、详情、产品介绍；
  • 外部链接：点击后跳转到指定网址；
  • 报名表单：配置报名字段，用户填写后数据进入「报名数据」；可开启「提交后允许修改」，让报名者自助更新已提交的信息；
  • 日程安排：以时间线展示日程，支持批量导入；
  • 我的二维码：为登录用户生成专属签到二维码。

模块可设置「开启 / 关闭时间」与「启用状态」，并可在「视觉编辑」中调整位置、颜色、圆角等样式。

导入账号（可选）

若微站需要登录访问（如定向邀请的活动），在「账号」标签下批量导入账号密码；并对每个账号勾选可访问的模块，实现 模块级权限。

上线

回到微站列表，点击「上线」按钮。上线会消耗 1 个 上线额度（无额度时请先在「会员中心」购买）。上线后用户即可通过 /s/{微站code} 访问。

验证：上线后用手机打开微站链接，确认 KV 图、模块、登录、报名与签到流程均正常，再对外正式分发。

03后台功能详解

按左侧菜单顺序介绍每个功能模块。标注 超管 的菜单仅超级管理员可见。

3.1 工作台

登录后默认进入工作台，集中展示：

  • 微站运营数据：微站总数、在线数量、累计访问量等；
  • 我的账户状态：钱包余额、会员有效期、剩余上线额度（不足时提供购买入口）；
  • 到期提醒：会员到期前 7 / 3 / 1 天顶部横幅提醒，到期后自动转只读。
权限差异：超级管理员在工作台看到 全局 数据（含收入统计：总充值、总消费、活跃会员数等）；管理员 / 子账号仅看到自己创建的微站数据。

3.2 微站管理

微站列表

  • 展示全部微站，含状态（草稿 / 在线 / 下线）、访问链接、创建时间；
  • 支持「上线」「下线」「编辑」「删除」操作；下线不退额度，再次上线需重新消耗 1 个额度；
  • 删除微站会级联删除其模块、账号、内容与统计数据，请谨慎操作。

创建 / 编辑微站

  • 创建流程：点击「创建微站」先进入模板选择页，套用模板或空白创建，再进入编辑器填写信息；
  • 基础信息：名称、编码、KV 图、背景色 / 背景图（KV 图与背景图均可一键「AI 生图」）；模板与布局随所选模板自动带入，也可在编辑器内调整；
  • 访问控制：是否需要登录、登录是否需要密码、整体开启 / 关闭时间、关闭提示文案；
  • 签到开关：开启后可在「签到管理」为该微站配置签到场次；
  • 分享配置：微信分享标题、副标题与分享图标（图标可用「AI 生图」一键生成）；
  • 客服配置：设置客服入口（如二维码 / 客服链接）。

模块类型详解

富文本

基于 wangEditor 的图文混排编辑器，支持多图上传（自动存储到 OSS）、段落样式、插入链接等。适合公告、活动详情、产品介绍等长内容。

外部链接

点击模块后直接跳转至外部 URL。常用于外链小程序、第三方报名系统、视频页等。

报名表单

可视化配置表单字段（姓名、手机号、自定义字段等），用户在 H5 端填写提交，数据沉淀在「报名数据」页，支持查看 / 备注管理；可开启「提交后允许修改」，并支持对单条记录锁定。

日程安排

以日期时间线展示日程条目（时间 / 主题 / 人员），支持下载模板、批量导入 CSV 快速录入。

我的二维码

为已登录用户生成专属签到二维码，现场核销员扫码即可完成签到。配合微站「签到管理」使用。

视觉编辑

  • 支持自由布局：在主页画布上拖拽模块位置（水平 / 垂直偏移）；
  • 模块级样式：按钮宽度 / 高度 / 圆角、背景色、文字颜色、图标位置、内容对齐、是否显示箭头；
  • 模块图标：在「图标选择」弹窗底部可一键「AI 生图」，为九宫格 / 按钮模块生成专属图标；
  • 九宫格布局支持垂直偏移微调（grid_offset_y），适配不同 KV 图高度。

3.3 模板管理 管理员及以上

模板是一整套「微站外观 + 预置按钮模块」的组合，用于快速批量建站。管理员（含超管）在左侧菜单「模板管理」中维护，所有用户创建微站时均可套用。

模板列表

  • 卡片网格展示全部模板，支持按名称关键字、启用状态筛选；
  • 支持新建 / 编辑 / 启用 / 停用 / 删除；系统内置模板带「系统」标签，不可删除；
  • 停用后该模板不再出现在创建微站的选择列表中，已创建的微站不受影响。

模板编辑器（可视化）

  • 外观设置：模板名称、描述、KV 图（可 AI 生成）、背景图 / 背景色（可 AI 生成）、模板风格（默认 / 经典蓝紫 / 暗夜科技 / 节日红金）、布局（九宫格 / 按钮 / 自由拖拽）、微信分享配置；
  • 页面元素：配置页面标题装饰（字体 / 颜色 / 大小 / 位置），管理预置按钮模块（增删、拖拽排序、启停用）；
  • 按钮模块：每个按钮可设标题、图标（可 AI 生成）、内容类型（富文本 / 外链 / 报名表单 / 日程 / 二维码）与按钮样式；
  • 预览图：上传模板封面图，不传时创建微站的选择页展示风格占位背景。
与微站的关系：套用模板创建微站时，系统会复制模板的外观配置并自动创建预置按钮模块，之后微站与模板各自独立——修改 / 删除模板不会影响已创建的微站。

3.4 账号管理（微站登录账号）

  • 进入微站编辑页的「账号」标签，可单个添加或批量导入登录账号（账号 / 密码 / 昵称 / 手机号）；
  • 对每个账号勾选可访问的模块，实现模块级权限控制；
  • 支持启用 / 禁用、重置密码、删除；同一微站内账号名不可重复。
场景：内部培训微站只对报名学员开放——导入学员账号，仅勾选培训资料模块，即可实现「专属内容」。

3.5 签到管理

项目与场次

  • 「签到管理」展示已开启签到的微站项目；进入后可为每个微站配置多个签到场次（如上午场 / 下午场、Day1 / Day2）；
  • 每个场次可设置名称、签到时间窗、启用状态与排序；
  • 场次创建 / 编辑 / 删除 不消耗上线额度（额度仅在上线时扣减）。

核销签到（PC 后台）

  • 打开对应场次，使用摄像头 / 扫码盒子扫描用户 H5 端的签到二维码完成核销；
  • 同一用户同一场次仅可签到一次，重复扫码会提示「已签到」。

移动端核销

  • 现场工作人员手机访问 /m/，用后台管理员账号登录；
  • 选择微站 → 选择场次 → 扫码签到；支持输入签到码（摄像头不可用时的兜底方式）；
  • 支持人工补签：按姓名 / 手机号 / 账号搜索 → 确认（选填补签原因）；补签需 admin 及以上角色；
  • 实时查看本场次签到名单（姓名、脱敏手机号、签到方式与时间），下拉刷新。
HTTPS 要求：手机摄像头扫码依赖浏览器摄像头权限，生产环境须在 HTTPS 域名下使用（微信内打开同样受限）。

记录管理

  • 支持对错误记录撤销签到（填写原因）；
  • 支持导出签到明细，用于会后核对与留存。

3.6 报名数据

  • 汇总该微站所有「报名表单」模块的提交记录；
  • 展示提交者姓名、手机号、提交内容与提交时间；
  • 支持添加管理员备注，用于跟进处理状态（备注仅管理员可见）；
  • 同一微站同一模块同一登录账号 仅保留一条有效记录，重复提交自动去重。

单条记录修改控制

  • 当表单开启「提交后允许修改」时，每条记录可切换可修改 / 禁修改：默认允许修改，报名者可在 H5 端自助更新；
  • 需要锁定某条数据时（如已审核、已分配名额），可切换为「禁修改」，该报名者将无法再修改自己的信息；
  • 表单模块级未开启「提交后允许修改」时，记录显示「已锁定」，数据级开关不生效。

3.7 AI 生图（内置微站编辑器）

AI 生图已集成到微站编辑器中：在需要图片的位置就地生成，无需切换页面、无需设计基础。共覆盖 4 类场景：

入口位置生成尺寸适用场景
KV 图「页面外观」面板 KV 上传区750 × 340顶部横幅
背景图「页面外观」面板背景设置750 × 1334页面全屏背景
分享图「微信分享」面板500 × 500微信分享卡片缩略图
模块图标模块「图标选择」弹窗底部128 × 128九宫格 / 按钮模块图标

使用步骤

  1. 进入微站编辑页，在对应图片区域点击「AI 生图」按钮（紫色魔法棒图标）；
  2. 在弹出的对话框输入画面描述，如「蓝色渐变科技风海报」；可选上传参考图做风格化（图生图）；
  3. 点击「立即生成」，约 10-60 秒出图（按张计费，余额不足时无法生成）；
  4. 在结果列表选一张满意的，点击「使用此图」自动回填到编辑器，可反复生成多张对比挑选；
  5. 点击页面底部「保存」按钮，H5 端立即生效。
  • 支持文生图（描述画面生成）与图生图（参考图风格化）两种方式；
  • 按生成张数计费（默认 0.1 元 / 张），从钱包余额扣除，生成失败的图片不扣费；超级管理员免扣费；
  • 生成结果自动保存到「AI 生图」独立页面，可随时查看历史、下载复用或删除；
  • AI 服务商与模型由超管在「管理员配置」中统一设置（默认通义万相，支持多种文生图模型）。

3.8 会员中心

  • 钱包余额：查看当前余额；余额不足时联系超管充值；
  • 购买会员：使用余额购买「年费会员」（默认 499 元 / 365 天），续费在现有到期时间上自动延长；
  • 购买上线额度：按场购买（默认 299 元 / 场，支持批量购买数量），额度 1 年内有效；
  • 交易流水：充值 / 消费 / 退款记录一目了然，可追溯。
余额不足时购买会被拦截并提示「余额不足，请联系管理员充值」。

3.9 后台账号管理 超管 / 管理员

  • 超级管理员可创建 / 编辑 / 禁用 / 删除任意角色账号（含管理员、子账号）；
  • 管理员仅可创建与管理自己的子账号（不能管理超管与其他管理员）；
  • 被禁用的账号无法登录后台；不能删除当前登录账号与超级管理员。

3.10 会员管理 超管

  • 会员列表：查看所有用户的会员状态、到期时间、钱包余额、剩余额度；
  • 钱包充值：确认收到客户款项后为用户充值（金额 + 备注必填）；
  • 退款：对购买流水执行退款，自动撤销对应权益并退回余额（已使用的场次额度不退）；
  • 套餐配置：编辑套餐名称 / 价格 / 时长 / 描述，可启停套餐（停用后用户不可购买）；
  • 流水查询：全量交易流水，支持按用户 / 类型 / 时间筛选。
调价促销：套餐价格可由超管随时调整（如限时折扣价），用户购买时以当前生效价格为准。

3.11 管理员配置 超管

  • H5 域名：对外域名配置，用于生成微站访问链接与二维码；
  • 微信分享：配置 AppID / AppSecret 后启用微信内分享（含分享标题、图标）；
  • OSS 存储：阿里云 OSS 配置（AccessKey / Bucket / Endpoint / 自定义域名），未配置时降级为本地存储；
  • AI 服务：配置 AI 生图服务商、API Key 与模型（默认通义万相，支持文生图 / 图生图）；
  • 图标库：管理本地图标库，供模块选择使用。

04H5 访客使用说明

面向终端用户（手机访问微站的人），可作为对外宣传材料的一部分。

4.1 访问与状态

  • 用户通过扫码或链接访问 /s/{微站code}；
  • 未到开启时间显示「敬请期待」；已关闭显示运营者配置的关闭文案；
  • 页面自动适配手机，视觉风格（模板 / KV / 背景）由运营者配置。

4.2 登录

  • 微站开启「需要登录」时，访问会先进入登录页（视觉与微站主页保持一致）；
  • 使用运营者分配的账号密码登录（是否需密码由运营者配置）；
  • 登录后仅展示被授权的模块；登录态保存在本机，下次访问自动进入。

05常见问题

FAQ — 覆盖上线、会员、额度、账号、签到等高频问题。

为什么「上线」按钮点不了，提示额度不足？
微站上线会消耗 1 个「上线额度」（默认 299 元 / 场）。请在「会员中心 → 购买上线额度」用钱包余额购买。额度购买后 1 年内有效，过期作废。
微站下线后，额度会退回来吗？
不会。下线不退额度；再次上线需要重新消耗 1 个额度。请确认活动不再需要后再下线。
会员到期后会发生什么？
到期后所有微站自动变为只读：H5 端仍可正常访问，但后台无法创建 / 编辑微站。在「会员中心」续费后立即恢复。
余额不足怎么充值？
当前版本由平台方（超级管理员）统一充值，不接入外部支付。请线下联系平台方完成转账，由超管在「会员管理」中充值到账。
子账号能买会员、用额度吗？
子账号（sub_admin）完全继承父账号的会员状态与上线额度，不单独扣费。子账号上线微站时扣减父账号的额度。
后台管理员账号和微站登录账号有什么区别？
两套独立体系。后台账号（左侧「账号管理」）用于登录管理后台；微站登录账号（微站编辑页「账号」标签）用于 H5 端访客登录。
想给访客设权限，只让部分人看到某些模块？
在微站编辑页「账号」标签下，对每个账号勾选可访问的模块即可。未勾选的模块该账号在 H5 端不可见。此功能要求微站开启「需要登录」。
现场签到怎么用手机核销？
工作人员手机访问 /m/，用后台管理员账号登录 → 选择微站 → 选择场次 → 扫描用户 H5 端「我的二维码」。也支持手动输入签到码与人工补签。注意需在 HTTPS 环境下使用摄像头。
同一用户重复报名 / 重复签到怎么办？
报名表单对「同一微站 + 同一模块 + 同一登录账号」自动去重；签到时同一用户同一场次仅可签到一次，重复扫码提示「已签到」。误操作可通过后台撤销签到（需填写原因）。
报名提交后，报名者还能修改自己的信息吗？
取决于两级开关：① 表单设计器开启「提交后允许修改」（模块级，默认关闭）；② 该条记录在「报名数据」中未被管理员设为「禁修改」（数据级，默认允许）。两级同时满足时，报名者再次进入表单即可直接修改并点「保存修改」；管理员也可随时对单条记录切换「禁修改」锁定。修改无次数限制，但系统不保留修改历史。
AI 生图怎么收费？
AI 生图按生成张数计费（默认 0.1 元 / 张），从钱包余额扣除；余额不足时无法生成。生成失败的图片不扣费。生成的历史图片可在「AI 生图」页面随时下载复用，不重复收费。超级管理员免扣费。
模板删除后，已经用该模板创建的微站会受影响吗？
不会。套用模板创建微站时，系统会把模板的外观配置与预置按钮复制到微站中，之后两者完全独立。删除或修改模板不会影响任何已创建的微站；模板停用后也不再出现在建站选择列表。
图片上传有什么限制？
支持 jpg / png / gif / webp 格式，单张最大 10MB。图片默认上传至阿里云 OSS；若未配置 OSS，自动降级为本地存储。
忘记后台密码怎么办？
联系超级管理员在「后台账号管理」中重置密码。被禁用的账号无法登录。
